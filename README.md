# 🎮 Clicker Game

Welcome to the official repository of this Clicker Game! / Willkommen im offiziellen Repository dieses Clicker-Spiels!

---

## 🌍 English Version

An interactive Clicker Game made for the web browser. Click the button, collect points, and rise to the top! This game is built completely from scratch using web technologies.

### 🚀 Features
* **Simple Gameplay:** Just click the main element to increase your score.
* **Modern Interface:** Designed with a clean and responsive look.
* **Play Anywhere:** Runs directly in any web browser without any installation.

### 🛠️ Built With
* **HTML5:** For the game structure.
* **CSS3:** For the styling and layout.
* **JavaScript:** For the game logic and score tracking.

### 💻 How to Run Locally
1. Clone this repository or download the ZIP file.
2. Open the project folder on your computer.
3. Double-click the `index.html` file.
4. The game will instantly open in your default browser!

## 🇩🇪 Deutsche Version

Ein interaktives Clicker-Spiel direkt für den Webbrowser! Klicke auf das Haupt-Element, sammle Punkte und klicke dich an die Spitze. Das Spiel wurde komplett selbst entwickelt.

### 🚀 Features
* **Einfaches Gameplay:** Klicke einfach auf das Element, um deine Punkte zu erhöhen.
* **Modernes Design:** Ein responsives, sauberes Interface für PC und Smartphone.
* **Sofort spielbar:** Läuft direkt im Browser, ohne dass man etwas installieren muss.

### 🛠️ Technologien
* **HTML5:** Für die Struktur des Spiels.
* **CSS3:** Für das Design und Layout.
* **JavaScript:** Für die gesamte Spiel-Logik und das Hochzählen der Punkte.

### 💻 Lokal starten
1. Klone dieses Repository oder lade die ZIP-Datei herunter.
2. Öffne den Projektordner auf deinem PC.
3. Mache einen Doppelklick auf die `index.html`-Datei.
4. Das Spiel öffnet sich sofort in deinem Webbrowser!
